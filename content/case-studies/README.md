# Case studies

MDX files, one per case study. Frontmatter validated against the
`CaseStudy` type (`types/models.ts`) — `outcomeVerified: true` is a hard
publish gate, and defence-related studies additionally require
`clearedForRelease: true`. Empty until at least one verified case study
exists (needed for Phase 2, `10-quality-and-launch.md` §4).
